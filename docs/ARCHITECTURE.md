# Architecture

The webview (TypeScript, xterm.js) draws the terminal and handles everything the user sees. Rust only runs `claude` in a pseudo-terminal (ConPTY on Windows, through `portable-pty`) and moves bytes in and out.

## How the webview may call Rust

- The app's commands are declared in `src-tauri/build.rs` (`AppManifest::commands`). Tauri then generates an `allow-*` and a `deny-*` permission for each one in `src-tauri/permissions/autogenerated/`.
- Without that declaration, Tauri lets any window with local content call every command registered in `invoke_handler`. With it, a command is refused unless a capability grants its permission to the calling window.
- `src-tauri/capabilities/default.json` grants the four commands below and the folder picker (`dialog:allow-open`) to the window labelled `main`, and nothing else. There is no shell permission and no permission to run an arbitrary command.

## Commands

Errors reach the webview as a plain message string.

### `pty_spawn`

Starts `claude` in a folder, in a new pseudo-terminal.

- **Arguments**: `folder` (string, absolute path), `cols` and `rows` (integers from 1 to 65535), `onOutput` (channel), `onExit` (channel).
- **Returns**: the session id (integer, starts at 1, never reused).
- **Streams**: `onOutput` receives the raw output bytes as `ArrayBuffer` chunks, in order. A chunk may end in the middle of a multi-byte character; xterm.js decodes the stream. `onExit` receives the exit code once, when `claude` ends. The session stays registered until `pty_kill`.
- **What Rust decides alone**: the program is `claude`, looked up on the app's `PATH`, with no argument. The working directory is the canonical form of `folder`. `TERM=xterm-256color` and `COLORTERM=truecolor` are added to the inherited environment. The webview cannot pass any argument or environment variable.
- **Refuses**: a relative folder path; a folder that does not exist; a path that is not a directory; a size of zero columns or rows; `claude` missing from the `PATH`; a pseudo-terminal that cannot be opened.

### `pty_write`

Sends input to a session.

- **Arguments**: `id` (integer), `data` (string, written as UTF-8).
- **Returns**: nothing.
- **Refuses**: an unknown id; a failed write.

### `pty_resize`

Changes the size of a session's terminal.

- **Arguments**: `id` (integer), `cols` and `rows` (integers from 1 to 65535).
- **Returns**: nothing.
- **Refuses**: an unknown id; a size of zero columns or rows; a failed resize.

### `pty_kill`

Stops a session's process and closes its pseudo-terminal. Also used to release a session whose process has already exited.

- **Arguments**: `id` (integer).
- **Returns**: nothing.
- **Refuses**: an unknown id.

When the app exits, every session still registered is stopped.
